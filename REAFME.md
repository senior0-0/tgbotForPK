Инструкция по настройке и запуску бота управления ПК

Описание проекта:
Этот скрипт позволяет удаленно управлять компьютером на базе Windows через Telegram-бота с помощью интерактивных кнопок. 

Основные возможности:
1. Создание и отправка текущего скриншота рабочего стола в чат.
2. Проверка свободного места на жестких дисках через запрос к PowerShell.
3. Удаленный перезапуск  ОС.
4. Удаленное выключение компьютера.
5. Доступ к управлению есть только у администратора по его Telegram ID.

Подготовка к запуску:
1. Установите необходимые библиотеки в терминале вашего проекта:
   pip install pyTelegramBotAPI pyautogui pillow pyscreeze

2. Откройте файл скрипта и настройте две переменные в начале кода:
   - Вставьте токен вашего бота в переменную TOKEN.
   - Вставьте ваш личный цифровой идентификатор в переменную ADMIN_ID.

3. Перед запуском бота убедитесь, что на компьютере включен VPN (это необходимо для стабильного обхода сетевых ограничений и связи с серверами Telegram).

Запуск:
Запустите скрипт через терминал с помощью команды:
py .\botForPK.py
